# Stego Jelly

Squishy jelly dinosaurs you can grab, stretch, and make sneeze: a Stegosaurus, a Brachiosaurus, and a Plesiosaurus cast in two layers of gummy jelly. Live at https://stegojelly.walker-robinson.com.

- Soft body: XPBD on a tetrahedral lattice, solved on the CPU.
- Rendering: WebGPU. It needs a recent desktop Chrome or Edge with graphics acceleration on; other browsers see a still frame.
- One self-contained file (`index.html`). No build step, no dependencies, no tracking.

Controls: left drag on the jelly stretches it or carries a drop; left drag on the table orbits; the wheel zooms or twists what you hold. The Controls button (bottom right) has species, colourways, firmness, and Sneeze.

Made by [Walker Robinson](https://www.walker-robinson.com) with Claude. Adapted from [Whale Jelly](https://x.com/vib3coded/status/2114674922802782355) by Vib3Coded.
